## Core Findings
1. **0/33** prior-injection configurations achieve spectral locking
2. **k-C framework** provides a 30-second audit for perturbation readiness
3. **Purity paradox**: pure priors cause spectral expansion (C<0); mixed priors enable critical regime
4. **G-VAE positive control: withdrawn** — the reported 21/21 locking (15 hemo + 3 neural + 3 lung BLM) is not reproducible (hemo 15/15 absent from checkpoints; fresh repro 1/3; neural/lung used non-differentiable k-C term)
5. **Label-shuffling control** is essential for CTCP methods
